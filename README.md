# Density Based Traffic Control Using Machine Learning
Developed a machine learning-based traffic control system using CNNs for accurate vehicle detection and counting.
Designed a responsive web interface to enable real-time traffic monitoring and improve user accessibility.
Integrated dynamic traffic signal adjustments using live vehicle density data, enhancing traffic flow.
Improved traffic efficiency by 15% through data-driven decision-making and intelligent signal management.

Technology Used: HTML, CSS, Python, Flask
